# PR #9823 测试用例解析

## 概述

本文档解析 `test_tracing_bkdata_pure.py` 中的 19 个测试用例，用于验证 PR #9823 的核心功能：**TRACING_ENABLE_BKDATA 全局开关**。

**PR 功能**：新增 `TRACING_ENABLE_BKDATA` 全局开关，支持 APM 应用接入 BKBase V4 数据链路。

**核心改动**：
- 当开关开启时，使用纯 V4 链路：从 BKBase 申请 `data_id`，使用 `bkapm` 命名空间
- 当开关关闭时，走传统 GSE 链路

**运行命令**：
```bash
PYENV_VERSION=bk-monitor python apm/tests/test_tracing_bkdata_pure.py
```

### 7. TestPureV4CreateDataId

测试纯 V4 链路下的 `create_data_id` 逻辑。这是 PR #9823 的**核心新增功能**。

**关联代码**：`bkmonitor/apm/models/datasource.py:555-624`

**核心逻辑**：
- 当 `TRACING_ENABLE_BKDATA=True` 时：
  1. 从 BKBase 申请 `data_id`，使用 `bkapm` 命名空间
  2. 轮询等待 `data_id` 返回（最多 5 次，间隔 3 秒）
  3. 创建 `metadata.DataSource` 记录，标记 `created_from=BKDATA`
- 当 `TRACING_ENABLE_BKDATA=False` 时：
  - 走传统 GSE 链路 (`super().create_data_id()`)
